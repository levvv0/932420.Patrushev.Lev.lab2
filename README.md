Описание страницы

1. Три способа подключения CSS

Основные правила находятся во внешнем файле style.css, подключённом через `<link rel="stylesheet" href="style.css">`.

Один элемент имеет inline-стиль: `<section id="projects" style="overflow: hidden;">`. Он ограничивает отображение смещаемого содержимого границами контейнера проектов.

В `<head>` расположен один внутренний блок `<style>` с одним правилом для h1, h2, h3. Оно задаёт заголовкам моноширинный шрифт из переменной --heading-font и межбуквенный интервал. Размеры заголовков и другие основные настройки находятся во внешнем файле. Внешние файлы шрифтов не требуются.

2. CSS-переменные

В :root объявлены общие значения:

--background - #050508 — основной глубокий чёрный фон

--surface - #10121c — фон карточек, формы и боковой панели

--text - #f1f5ff — основной светлый текст

--accent - #00d9ff — электрический голубой акцент

--secondary - #ff83d8 — розовый неоновый акцент

--body-font - Arial, sans-serif — основной шрифт

--heading-font - "Courier New", monospace — шрифт заголовков

Правила получают значения через var(), например color: var(--text).

3. Позиционирование

static применяется в section. Разделы остаются в обычном потоке документа.

relative применяется в header. Шапка остаётся в потоке и становится точкой привязки для фотографии

absolute применяется в img. Фотография располагается в правом верхнем углу шапки через top: 0 и right: 0

Правый внутренний отступ шапки оставляет место для фотографии. Минимальная высота шапки не позволяет следующему контенту занять область изображения.

4. Состояния элементов

:hover - .card - Текст карточки сдвигается на 2 px вправо и на 2 px вверх; цветные тени смещаются в противоположные стороны

:hover - Ссылки и кнопка - У ссылки меняется цвет текста, у кнопки — фон

:active - Неоновый заголовок и текст карточек- Пока нажата основная кнопка мыши, обводка отключена через text-shadow: none

:active - Ссылки и кнопка - Используется розовый акцент

:focus - Ссылки, поля формы и кнопка - Появляется розовая рамка фокуса

:visited- Ссылки - Посещённые ссылки становятся розовыми

5. Неоновое оформление и глитч-эффект

Класс .neon создаёт обводку текста четырьмя тенями: справа, слева, сверху и снизу. Класс применён к главному заголовку и тексту карточек.

При наведении на карточку используется transform: translate(2px, -2px) и две смещённые тени разных цветов. Получается глитч-эффект.

6. Типографика, отступы и размеры

Основной текст имеет размер 16 px и межстрочный интервал 1.6. Заголовки имеют размеры 40, 24 и 20 px. Центральные блоки ограничены шириной 1000 px. Для расстояний между блоками используется margin, для внутренних отступов — padding. Правило box-sizing: border-box включает рамку и внутренние отступы в заданную ширину.
